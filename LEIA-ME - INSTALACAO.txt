4. Nunca apague dados ou substitua a versão de trabalho antes de conferir um backup.

IMPORTANTE SOBRE GOOGLE APPS SCRIPT
O editor do Apps Script não oferece diretórios js/, css/, img/ servidos estaticamente como um servidor web tradicional.
O pacote desta pasta não pode ser colado integralmente no Apps Script e publicado com as URLs relativas; ele é para estrutura de SITE ESTÁTICO.
Para publicar no Apps Script, será necessário adaptar a carga dos arquivos pelo HtmlService, por exemplo incluindo o CSS e JavaScript como arquivos HTML do projeto ou usando hospedagem externa.
NÃO basta publicar o Index/index.html no Apps Script: as URLs ../js e ../css não são servidas por ele.
A mera divisão dos arquivos também NÃO implementa sincronização entre computadores.

ATENÇÃO A DADOS PESSOAIS
Não publique registros reais de acolhidos em hospedagem pública sem autenticação efetiva no servidor, armazenamento seguro, backups e avaliação de privacidade.
Uma restrição apenas na interface HTML não é uma barreira de segurança.
